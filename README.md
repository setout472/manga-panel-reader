# 逐格 Manga Panel Reader

**把漫画整页转换为可调整顺序的画格，让小屏阅读更轻松。**

## 项目简介

逐格是一个面向 Windows 的本地漫画阅读器，支持整页与逐格阅读，并允许读者调整自动识别结果，在保留页面上下文的同时改善阅读体验。

## 主要功能

- **导入与阅读**：支持本地图片、PDF，以及特定来源的章节适配；可切换整页和逐格视图。
- **自动分格与人工修正**：通过本地模型检测画框，并允许调整、排序与覆盖结果。
- **阅读辅助**：提供本地 OCR 原文与定位、对照及修正记录。
- **本地优先**：原图、阅读进度和缓存保存在本机，云端接口为可选项。

**技术与实现**：Electron、React、TypeScript、Vite、ONNX Runtime 和 PDF.js。

**项目状态**：开发中的预览作品。模型及素材未包含在仓库中，本仓库不提供可直接下载的安装包；复杂排版、OCR 和内容理解仍需人工核对。使用云端分析时，所选图片会发送给配置的服务商。
