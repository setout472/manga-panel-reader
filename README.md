# 逐格 | Manga Panel Reader

> 一个面向漫画页面的 Windows 桌面阅读器：把整页拆解为可调整顺序的画格，让小屏阅读更轻松。

**项目状态：开发中的个人作品 / Preview**。本仓库展示应用源码与技术设计；已在原开发机验证的 preview.13 打包版本不等于本仓库包含可下载的安装包。

## 它解决什么问题

传统整页漫画在小屏幕上文字与画面偏小。逐格将漫画页作为有序画格阅读，保留整页上下文，并允许用户手动调整检测结果。默认右向左，同时支持切换方向。

## 功能概览

- **导入与阅读**：本地图片、PDF，以及针对特定漫画来源的章节适配；整页/逐格切换、缩放和跨页导航。
- **自动分格与修正**：Windows CPU 本地模型检测画框；人工调整、排序和覆盖优先。源码包含阅读范围留边和旧检测缓存重排的后续改进，尚未随 preview.13 发布。
- **阅读辅助**：本地 OCR 原文及定位、候选对照、整页修正笔记和历史；结果需要人工核对。
- **数据与安全**：原图、进度及缓存保存在本机；云端接口为可选项，密钥由 Electron 主进程管理。模型和漫画素材不包含在本仓库中。
- **实验方向**：连续页面内容理解与解说草稿已有原型，尚未达到可靠自动解说的质量；不包括自动配音或视频发布。

## 技术设计

`Electron + React + TypeScript + Vite`，主进程通过类型化 IPC 管理文件、任务与模型；渲染进程负责阅读和纠错。专用分格使用独立可终止的 ONNX Runtime CPU 进程，缓存按模型与图片版本区分；人工修订不被自动分析覆盖。PDF 页面使用 PDF.js 渲染。

## 当前验证与限制

在原开发环境，已发布 preview.13 完成实际 Windows EXE 冒烟、模型资源校验、缓存/人工修正/重启测试；随后源码版的阅读留边与排序改进曾完成 385 项单元测试和 29 项桌面测试。**测试覆盖软件行为，不等同于模型准确率。**复杂嵌套、越框人物、OCR 及剧情理解仍需人工检查；独立 20 页质量验收尚未完成。

## 运行源码

需要 Windows、Node.js、npm：

```powershell
npm ci
npm run start
```

基础整页阅读与手工分格不依赖云端 Key。专用本地分格和 OCR 还需要单独准备模型及运行时资源；它们因体积和许可管理不在此快照中。资源缺失时专用能力不可用或回退，**本快照尚未提供一键资源安装或发布包**。源码里的打包脚本依赖开发机上的资源目录，当前不能保证克隆后直接打包。

## 隐私与素材

本仓库不含个人漫画库、Key、真实漫画样本、模型权重或试验日志。仅使用有权使用的漫画内容；云端分析会将所选图片发送给配置的服务商，应先确认服务商与数据处理方式。
